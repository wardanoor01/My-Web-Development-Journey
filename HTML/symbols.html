Here are the common HTML symbols in text form:

Basic Symbols

Less Than: `<` → `<` Greater Than: `>` → `>` Ampersand: `&` → `&` Double Quote: `"` → `"` Single Quote: `'` → `'`

Copyright & Legal Symbols

Copyright: © → `©` Registered: ® → `®` Trademark: ™ → `™` Service Mark: ℠ → `℠`

Currency Symbols

Dollar: $ → `$` Euro: € → `€` Pound: £ → `£` Yen: ¥ → `¥` Cent: ¢ → `¢` Rupee: ₹ → `₹`

Mathematical Symbols

Plus: + → `+` Minus: − → `−` Multiplication: × → `×` Division: ÷ → `÷` Equal: = → `=` Not Equal: ≠ → `≠` Approximately Equal: ≈ → `≈` Less Than or Equal: ≤ → `≤` Greater Than or Equal: ≥ → `≥`

Arrow Symbols

Left Arrow: ← → `←` Right Arrow: → → `→` Up Arrow: ↑ → `↑` Down Arrow: ↓ → `↓` Left-Right Arrow: ↔ → `↔`

Other Common Symbols Heart: ♥ → `♥` Star: ★ → `★` Check Mark: ✓ → `✓` Cross Mark: ✗ → `✗` Bullet: • → `•` Ellipsis: … → `…` Degree: ° → `°` Paragraph: ¶ → `¶` Section: § → `§` Non-Breaking Space → ` `
